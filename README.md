# 人生档案 · 本地交互演示

双击 `打开演示.bat`，或直接使用浏览器打开 `index.html`。

## 当前页面结构

软件现在只保留五个一级入口：

- 今日：状态、三件重要行动、今日经验和今日旁白
- 成长：人生等级、六项属性、当前章节、人生地图与人生树
- 记录：日记时间线、回忆胶囊、年度档案、思想档案和阶段报告
- 空间：主题切换、壁纸、成长房间和人生物品
- 我的：个人资料、档案概览和本地数据管理

复杂内容默认折叠。人生地图和年度档案只在用户主动查看时展开，避免日常使用时被大量数据包围。

## 人生空间主题

- 雾白 Morning Mist
- 植物玻璃 Greenhouse
- 深夜 Night Archive
- 陶土书房 Clay Room

主题会同步改变壁纸、卡片、文字、强调色、弹窗和开场动画，并保存在当前浏览器中。

## 使用提示

- 在“今日”创建现实行动，并按“起步 / 完成 / 突破”结算经验。
- 在“成长”展开人生地图，可查看对应的成长节点。
- 在“记录”点击“保存回忆”，可创建回忆胶囊。
- 在“空间”切换人生主题。
- 页面数据只保存在当前浏览器的本地存储中；“我的”页面底部可以恢复初始演示数据。
